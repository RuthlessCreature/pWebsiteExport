China sourcing buyer guide

Consolidation is procurement control plus warehouse control—not just putting cartons together.

Combining goods from several Chinese suppliers can reduce fragmented international shipments and simplify buyer-side receiving, but it creates a new coordination problem in China. Each factory has its own completion date, carton format, shipping mark and documentation. A consolidation plan turns those separate deliveries into one controlled outbound shipment.

Buyer control points

A process that can be checked, not guessed.

Use this guide as an operating framework and adapt the depth of control to product risk, order value, customization and destination-market requirements.

Working checklist

  • Master supplier/SKU register
  • Warehouse receiving instructions
  • Factory delivery dates
  • Carton count and dimensions
  • Shortage/damage record
  • Final shipping marks
  • Repacking/kitting record
  • Consolidated packing list
  • Commercial invoice responsibility
  • Forwarder handoff data
01

Build one master inbound register

Before suppliers send goods, record expected SKU, quantity, carton count, factory, contact, planned arrival and any special handling. Give suppliers consistent receiving instructions and reference numbers so warehouse staff can reconcile deliveries without relying on memory.

02

Control the delivery window

The earliest supplier should not force the entire shipment schedule, and the latest supplier should not be invisible until the final day. Track factory readiness and decide a warehouse cutoff. For project shipments, separate urgent items from goods that can wait for the next consolidation cycle.

03

Reconcile cartons and SKU quantities on receipt

Receiving should confirm the supplier delivery against the expected register. Record shortages, obvious damage, label problems and carton data. If the consolidation point is also performing inspection, kitting or relabeling, define those tasks separately from basic receiving.

04

Standardize shipping marks and documentation

Different factories often use different carton labels or product descriptions. Decide whether marks need normalization and create one final packing-list structure. Commercial invoice and export documentation responsibilities should be clear before the freight booking is finalized.

05

Use repacking only when it creates value

Repacking can improve carton utilization, protect mixed goods or create retail kits, but it also introduces handling risk. Preserve SKU identification and verify final quantities after any repacking or kitting. For fragile, regulated or warranty-sensitive products, unnecessary repacking may be counterproductive.

06

Handoff to the forwarder with one final data set

The freight forwarder should receive confirmed carton count, dimensions, weight, pickup address, packing list and any special handling information. A clean handoff reduces last-minute changes and gives the buyer one set of shipment data instead of separate factory versions.
